# План: Фильтры + Пагинация (Аренда)

Цель: при росте каталога вилл пользователь не тонет в списке —
выбирает критерии (спальни / пляж / цена) и листает страницы по 10 объектов.

## Этап 5 — Callback-маршруты (CallbackHandler)

Новые data-паттерны (все ≤ 64 байт):

| callback | действие |
|---|---|
| `rent_filters` | показать экран фильтров (с текущим state) |
| `f_bed_<n>` | state.filter.minBedrooms = n, перерисовать экран фильтров |
| `f_beach_<idx>` | state.filter.beach = beaches[idx], перерисовать |
| `f_price_<n>` | state.filter.maxPrice = n, перерисовать |
| `rent_list` | применить фильтр, page = 0, показать страницу |
| `rent_page_<n>` | state.page = n, показать страницу |
| `rent_reset` | очистить state, показать экран фильтров |

## Ограничения Telegram (учесть при реализации)

- `callback_data` ≤ 64 байт → состояние в `ChatStates`, в кнопке только ключи
- Текст сообщения ≤ 4096 символов
- Кнопок в строке ≤ 4 → фильтры группировать по строкам
- Кнопок в сообщении ≤ 100 → PAGE_SIZE = 10 с запасом
